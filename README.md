## Реализация

Проект написан на C++17. В программе реализованы:

- скалярный метод Ньютона для уравнения `(x + 3)cos(x) = 1`;
- локализация корней скалярного уравнения и выбор минимального по модулю ненулевого корня;
- полный метод Ньютона для системы;
- модифицированный метод Ньютона;
- переход к модифицированному методу после `k` начальных пересчетов матрицы Якоби;
- циклический вариант с пересчетом матрицы Якоби каждые `m` итераций;
- единая реализация метода для системы через параметры `m` и `k`;
- LU-разложение для решения линейных систем;
- подсчет итераций, пересчетов матрицы Якоби, арифметических операций и времени;
- проверка решения через норму невязки `||F(x)||_inf`;
- отдельный эксперимент для начального приближения с `x_5^{(0)} = -0.2`.

Для системы на каждой итерации решается СЛАУ

$$
J(x_k)\Delta x_k = -F(x_k),
$$

после чего новое приближение находится по формуле

$$
x_{k+1} = x_k + \Delta x_k.
$$

## Параметры метода

В коде используется единая функция Ньютона с двумя параметрами:

- `k` (`full_jacobian_iterations`) - сколько первых итераций матрица Якоби пересчитывается каждый раз;
- `m` (`jacobian_recalculation_period`) - как часто пересчитывать матрицу Якоби после первых `k` итераций.

Частные случаи:

- `m = 1`, `k = infinity` - полный метод Ньютона;
- `m = infinity`, `k = 1` - модифицированный метод Ньютона;
- конечные `m` и `k` - смешанный/циклический вариант.

## Структура проекта

- `main.cpp` - запуск основных экспериментов и печать таблиц результатов;
- `include/types.hpp` - общие типы `Vector`, `Matrix` и счетчик операций;
- `include/scalar_newton.hpp`, `src/scalar_newton.cpp` - скалярный метод Ньютона для уравнения варианта 20;
- `include/nonlinear_system.hpp`, `src/nonlinear_system.cpp` - система `F(x)`, матрица Якоби `J(x)` и начальные приближения;
- `include/linear_solver.hpp`, `src/linear_solver.cpp` - LU-разложение и решение СЛАУ;
- `include/newton.hpp`, `src/newton.cpp` - общий метод Ньютона с параметрами `m` и `k`.

## Выводы

- Полный метод Ньютона быстро сходится по числу итераций, но требует пересчета матрицы Якоби на каждом шаге.
- Чистый модифицированный метод использует только одну матрицу Якоби, но сходится значительно медленнее и при заданной точности не выполнил критерий остановки.
- Смешанный вариант оказался эффективнее: для исходного начального приближения лучшим среди проверенных стал `k = 4`.
- В циклическом варианте по числу операций лучшим стал `m = 4`.
- При изменении начального приближения на `x_5^{(0)} = -0.2` поведение метода меняется: некоторые значения `k` не сходятся за заданное число итераций.
